Kenapa CONGOK-rs

Semua yang kamu butuhkan,
tanpa yang tidak kamu butuhkan.

Setiap layer dipilih dengan satu prinsip: tulis sedikit, jalankan cepat, ubah mudah.

Modular Routing

Setiap fitur punya folder src/module/{nama_module}/ sendiri. Route terdaftar lewat open_routes dan gate_routes.

SQLx MySQL Native

Query compile-time checked langsung ke MySQL. Pool siap pakai di setiap handler tanpa konfigurasi manual.

Session Auth Bawaan

Autentikasi berbasis actix-session sudah terintegrasi. Guard lewat macro auth! — satu baris, dijamin terisi.

Server-Side HTML

HTML murni di dalam folder module masing-masing. Tidak ada template engine baru atau gunakan Petite-Vue untuk interaktivitas ringan.

bcrypt Password Hash

Password hashing dengan bcrypt sudah tersedia out-of-the-box. Tidak ada setup tambahan yang perlu dilakukan.

Type Alias Konsisten

Alias seperti Pool, Request, Response membuat setiap handler terlihat seragam dan mudah dibaca tim.

Quick Start

Module baru dalam 3 langkah.

mod.rs → handler.rs → HTML. Itu saja.

// src/module/profile/mod.rs
pub mod handler;

use actix_web::web::ServiceConfig;

// Route tanpa auth — bisa diakses publik
pub fn open_routes(cfg: &mut ServiceConfig) {
    // kosong jika semua route butuh auth
}

// Route dengan auth — wajib login
pub fn gate_routes(cfg: &mut ServiceConfig) {
    cfg.service(
        actix_web::web::resource("/profile")
            .route(actix_web::web::get().to(handler::index))
    );
    cfg.service(
        actix_web::web::resource("/profile/update")
            .route(actix_web::web::post().to(handler::update))
    );
}
// src/module/profile/handler.rs
use crate::web::{Pool, Session, Response, ApiResponse};

pub async fn index(
    session: Session,
    pool: Pool,
) -> Response {
    let user_id = auth!(session);

    let html = include_str!("page_profile.html");
    Response::Ok()
        .content_type("text/html; charset=utf-8")
        .body(html)
}

pub async fn update(
    session: Session,
    pool: Pool,
) -> Response {
    let user_id = auth!(session);
    // ... proses update
    Response::Ok().json(ApiResponse {
        success: true,
        message: "Profil diperbarui".into(),
        data: None,
        meta: None,
    })
}
