pub async fn dashboard(
    session: Session,

Kenapa Sapi-rs

Semua yang kamu butuhkan,
tanpa yang tidak kamu butuhkan.

Setiap layer dipilih dengan satu prinsip: tulis sedikit, jalankan cepat, ubah mudah.

Zero-boilerplate Routing

Daftarkan route di main.rs dan handler siap dipanggil. Tidak ada magic, tidak ada macro tersembunyi.

SQLx MySQL Native

Query compile-time checked langsung ke MySQL. Pool siap pakai di setiap handler tanpa konfigurasi manual.

Session Auth Bawaan

Autentikasi berbasis actix-session sudah terintegrasi. Guard, login, logout — tinggal pakai.

Server-Side HTML

HTML murni di src/page/. Tidak ada template engine baru untuk dipelajari — gunakan HTMX dan Alpine.js untuk interaktivitas.

bcrypt Password Hash

Password hashing dengan bcrypt sudah tersedia out-of-the-box. Tidak ada setup tambahan — keamanan default yang benar.

Type Alias Konsisten

Alias seperti Pool, Request, Response membuat setiap handler terlihat seragam dan mudah dibaca tim.

Quick Start

Halaman baru dalam 3 langkah.

Route → Handler → HTML. Itu saja.

// src/main.rs — daftarkan satu baris
App::new()
    .route(
        "/profile",
        web::get().to(handler::profile::index)
    )
    .route(
        "/profile/update",
        web::post().to(handler::profile::update)
    )
// src/handler/profile.rs
use crate::web::{Pool, Request, Response};
use actix_session::Session;

pub async fn index(
    session: Session,
    pool: Pool,
) -> Response {
    let user_id: i32 = match session.get::<i32>("user_id") {
        Ok(Some(id)) => id,
        _ => return Response::Found()
              .insert_header(("Location", "/login"))
              .finish(),
    };

    let html = include_str!("../page/profile.html");
    Response::Ok()
        .content_type("text/html; charset=utf-8")
        .body(html)
}
